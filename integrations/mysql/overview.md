### Monitor MySQL with FuseScope

Collect MySQL server metrics with the OpenTelemetry `mysql` receiver and view throughput, connections, InnoDB buffer pool, locks and replication lag on an out of the box dashboard.

Collect the MySQL error log and slow query log. Installed log pipelines parse them into timestamp, severity, error code, query time, rows examined and other attributes for querying and aggregation.

Works with MySQL 5.7, 8.x and 9.x, and with MariaDB.
